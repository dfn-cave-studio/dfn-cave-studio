# Synthetic multi-source import examples

These files contain invented identifiers and coordinates. Import collars first or deliberately import dependent tables first to inspect Pending → Formal reconciliation. For `fractures_spacing.csv`, select **B — Interval spacing** and **cm**. For `fractures_axis_angle.csv`, select **C — Borehole-axis angle**.

The examples verify import and audit contracts only. They do not provide direction completion or a calibrated geological model.

`orientation_points.csv` uses the fixed P/Z contract. P rows are point-cloud/work-face summaries, including an optional RANDOM background component. Z rows are borehole-camera directions and therefore leave spacing and count empty. `local_set_id` is local to one point and is never treated as a global DFN `set_id`.
